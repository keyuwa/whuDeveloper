# WHU TOP Developer 使用指南

欢迎使用 WHU TOP Developer。这里可以找到助教、开发、科研、项目四类机会，完成申请、入项协作，并在 WHU Dev 里积累积分与能力展示。

**小提示**
- 学生在站内对外显示**昵称**；发布方使用**真实姓名**。
- 未登录也可以逛任务广场；投递、私信和协作需要先注册登录。

---

## 一、注册与登录

1. 打开「注册」，选择身份：**学生**或**发布方**。
2. 填写邮箱，获取验证码，设置密码（至少 8 位）。建议使用学校邮箱。
3. 学生填写昵称；发布方填写真实姓名。
4. 完成后即可登录使用。

登录后：
- **学生**：任务广场、工作台、WHU Dev、私信；手机端还有「我的」。
- **发布方**：任务广场、我的任务、审阅、WHU Dev、私信。

---

## 二、学生怎么用

### 1. 先完善简历

申请前请先填写简历（电脑端点「简历」，手机端在「我的」里）。

请至少填写：姓名、学校、学院、专业、在读身份、个人简介（建议写满 20 字以上）。也可以上传简历 PDF。

简历不全时，任务详情页会提示你先去完善。

### 2. 在任务广场找机会

打开「任务广场」，顶部四个频道：

| 频道 | 适合谁 |
|------|--------|
| **助教** | 想做课程答疑、教学协作 |
| **开发** | 想做产品功能、工程实现 |
| **科研** | 想揭榜开放研究方向，提交方案竞标 |
| **项目** | 想做运营、标注等协作，按岗位报名 |

可以按条件筛选，也可以先点「备选」收藏，稍后再申请。

### 3. 提交申请

1. 点进任务，仔细阅读背景、产出要求和能力要求。
2. 有问题可以点「立即沟通」私信发布方。
3. 在申请区填写文字，或上传 PDF（不超过 5 MB），**至少提供一种**。
4. 如果是「项目」频道，**请先选择有名额的岗位**，再提交。
5. 每个任务只能申请一次。提交后可在工作台「已申请」里查看进度。

申请状态一般是：待审阅 → 已通过 / 未通过。通过后即入项，可进入协作。

### 4. 在工作台推进项目

工作台按四个频道分栏，可以看到：

- **已接项目**：已经通过、正在协作的
- **已申请**：还在等结果的
- **备选项目**：收藏过但还没投的

进入已接项目后，常用三个页签：

| 页签 | 做什么 |
|------|--------|
| 项目详情 | 查看任务约定与信息 |
| 推进与周报 | 按周写进展：做了什么、卡在哪、下一步 |
| 结项验收 | 提交结项说明 / PDF / 仓库或 PR 链接，等待发布方验收 |

需要中途离开时，按项目内提示操作即可。

## 三、发布方怎么用

### 1. 发布任务

在「我的任务」里新建，选择类型并填写信息：

- **助教**：学期、面向哪些在读身份、每周投入等
- **开发**：技术领域、难度、开发周期；通常需要上传需求文档
- **科研**：揭榜形式，可设置名额和截止时间（也可长期开放）
- **项目**：一次挂多个岗位和名额，学生按岗位报名

可以先存草稿，确认后再发布。也可以随时下架；招满或揭榜结束后会自动关榜。

### 2. 审阅申请

在「审阅」里处理学生申请：

1. 查看简历摘要和申请内容（含 PDF）。
2. 科研任务若开通了 AI 可行性初判，仅作参考，**是否通过仍由你决定**。
3. 通过：学生入项，开始协作；不通过：填写意见后拒绝。
4. 「项目」按岗位审阅；某个岗位招满后，该岗位的待审申请会一并处理完。

### 3. 带队协作

学生入项后，你可以：

- 查看申请原文
- 阅读周报并给出评分与反馈
- 验收结项材料，决定通过或不通过

结项通过后，这段协作就结束了。

---

## 四、私信与通知

- 在任务详情或广场可与对方开启私信，讨论需求和进度。
- 顶部铃铛可查看站内通知（新申请、审阅结果、催办等）。

请及时回复消息，方便双方推进。

---

## 五、WHU Dev

入口在导航「WHU Dev」。

- **积分与排行榜**：入项、提交周报、收到周报反馈、结项通过等会累计积分，用于排行展示。
- **能力等级（LV0–LV5）**：与积分排行相互独立。细则见站内「等级评定细则」。
  - LV1–LV3：按已完成工作由系统自动评定（以细则为准）。
  - LV4–LV5：需要申请，并由管理员或高阶裁定人终裁。

积分高不等于等级自动升；等级按细则评定。

## 六、常见问题

**为什么点不了申请？**  
请先登录并完善简历，并确认任务仍在开放中。科研揭榜还要确认没过截止时间。

**「项目」为什么要选岗位？**  
一个任务下可能有多个岗位、名额分开。选好岗位后，会按该岗位审阅和入项。

**同一个任务能申请几次？**  
只能一次。

**申请内容有什么要求？**  
文字或 PDF 至少填一种；PDF 不超过 5 MB。

**AI 初判是最终结果吗？**  
不是，只是帮发布方更快读懂科研方案，入项与否由发布方决定。

**积分高了等级会自动升吗？**  
不会。积分用于激励和排行；能力等级按细则单独评定。
